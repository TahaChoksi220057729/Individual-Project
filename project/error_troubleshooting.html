MUN Speech Evaluator - Troubleshooting Guide

Quick Start Guide

To get started with the improved MUN Speech Evaluator:

  1. Update your training data:
    python add_common_topics.py
    This adds speeches for 16 common MUN topics to ensure better model compatibility.
  2. Refresh your models:
    python refresh_models.py
    This creates both a topic-based model and a safe mode model to handle all evaluation scenarios.
  3. If you encounter model loading errors:
    python reset_models.py
    This will delete all existing model files and create fresh ones.
  4. Start the web application:
    python app.py
    Access the interface at http://localhost:5000
  5. Or use the command line:
    python evaluate_speech.py --topic "Climate Change"
    Add --safe-mode flag if you encounter feature mismatch errors.

Troubleshooting Feature Mismatches

If you encounter an error similar to: Error: X has 1495 features, but RandomForestRegressor is expecting 1494 features as input, this indicates a feature dimension mismatch between your model and the speech being evaluated.

Common solutions:

  1. Leave the topic field empty (this always works but may provide less accurate scoring)
  2. Use only topics that were included in the training data
  3. Enable the "Safe mode" checkbox in the web interface
  4. Run refresh_models.py to update your models with common topics

Command-Line Alternative

You can use the command-line tool for speech evaluation:

python evaluate_speech.py --topic "Your Topic" --safe-mode

The --safe-mode flag ensures the topic is only used for feedback generation, not for scoring, which avoids feature dimension mismatches.

Training with Common Topics

For best results, ensure your model is trained with the most common MUN topics:

  • Climate Change
  • Nuclear Disarmament
  • Human Rights
  • Maritime Security
  • Refugee Crisis
  • Sustainable Development
  • Cyber Security
  • Terrorism
  • Economic Development
  • Healthcare
  • Education
  • Gender Equality
  • Water Security
  • Food Security
  • Peace and Security
  • International Law

You can add all these topics to your training data by running:

python add_common_topics.py

Retraining the Model

If you've added new topics to your training data, you should retrain the model:

  1. Add training data with collect_training_data.py or add_common_topics.py
  2. Retrain with refresh_models.py
  3. If you encounter issues with corrupt models, run reset_models.py to create fresh models
  4. If problems persist, delete existing model files to force a complete retraining

Technical Details

Understanding how topics affect the model:

  • Topics are one-hot encoded as features during model training
  • When a new topic (not seen during training) is used for evaluation, it creates a feature dimension mismatch
  • The safe mode model excludes topic features entirely, making it more robust but potentially less accurate
  • Using add_common_topics.py adds the most common MUN topics to prevent most mismatches
